# 🛒 E-Commerce Website

A modern and responsive **E-Commerce Website** built using **HTML, CSS, and JavaScript**.

This project focuses on creating a smooth shopping experience with a clean UI, responsive design, product browsing, and interactive cart functionality.

## ✨ Features

* 🏠 Clean & modern homepage
* 📱 Fully responsive design
* 🛍️ Product listing and product cards
* 🛒 Add products to cart
* ➕ Increase / decrease product quantity
* ❌ Remove products from cart
* 💰 Dynamic cart total
* ⭐ Customer review section
* 📱 Mobile-friendly navigation
* 🎨 Modern UI with smooth hover effects and animations

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout & responsive design
* **JavaScript** — Dynamic functionality and cart logic
* **Font Awesome** — Icons
* **Google Fonts** — Typography
* **Swiper.js** — Review/slider section
